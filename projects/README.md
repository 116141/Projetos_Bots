# Projetos de Bots de Automação

Esta pasta conterá os repositórios dos projetos de bots a desenvolver:

- `bot_trading_crypto/`: Bot de negociação algorítmica (Python + CCXT / Freqtrade).
- `bot_afiliados_telegram/`: Bot de captura de ofertas e publicação em grupos.
- `bot_mining_monitor/`: Script de monitorização de rentabilidade de mineração.
